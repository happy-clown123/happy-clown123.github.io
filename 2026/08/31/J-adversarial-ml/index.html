对抗机器学习（J 模块）

模块 J：对抗机器学习（Adversarial Machine Learning）

本文行动导航：FGSM 后立刻做 J01 并读 Goodfellow 2014；PGD/对抗训练后做 J02 并读 Madry 2017；Poisoning/Backdoor 后做 J03 并对照 Sleeper Agents/Nightshade。每次必须同时报告干净指标、攻击指标、威胁模型和攻击预算。

定位：研究“AI 本身的安全问题”的算法基础——攻击者怎样让模型做错事，防御者怎样在明确威胁模型下评估和缓解风险。与模块 K（大模型安全）交替学习：prompt injection 与对抗样本都研究“攻击者控制输入后系统如何偏离目标”，但前者主要利用指令/数据边界，不能直接等同为范数约束下的文本对抗样本；RAG 投毒与训练数据 poisoning 也只在“非可信数据影响输出”的抽象层相似。
前置：模块 D（深度学习基础：梯度、损失、backprop 直觉）、E（PyTorch）｜ 后继：模块 K（大模型安全）
及格线：能手写 FGSM/PGD 公式并解释每一步；用 CPU 跑通 J01/J02，说明 PGD 何时可能比一步攻击更强、对抗训练的保证为什么受威胁模型与评测攻击限制。

1 先建立直觉：从个别 bug 转向系统性威胁模型

2013–2015 年的经典工作表明：在特定模型、输入和扰动预算下，人眼不易察觉的图像扰动可以让分类器高置信度误判；Goodfellow 论文中的“熊猫→长臂猿”是一个著名示例，不是所有样本和模型都会得到相同置信度。

关键认知——对抗脆弱性已在许多模型、数据集和威胁模型中反复出现，不能只当作某一份代码的偶发 bug；但也不能据此断言“所有模型对所有微小扰动都脆弱”。模型可能依赖人类不敏感却具有预测性的统计特征，攻击者会利用这些特征与决策边界。

一旦你接受”脆弱性是内生的”，研究重点就从”修 bug”变成”在威胁模型下量化并缓解风险”——这正是本模块的全部内容。

2 攻击分类：按攻击者介入的阶段切分

最实用的分类维度是攻击者在 ML 生命周期的哪个阶段动手：

阶段 攻击类型 含义 典型手法
数据准备/训练时 Poisoning 投毒 篡改训练数据，造成可用性、定向或 clean-label 操纵 label flipping、注入恶意样本
数据准备/训练时 Backdoor 后门 植入 trigger-conditional behavior，尽量维持干净效用 在部分样本贴触发图案后改标签
供应链/加载/部署时 供应链攻击 篡改第三方数据、权重、依赖或构建产物 发布被篡改的模型、包或镜像；加载时执行恶意逻辑
推理时 Evasion 对抗样本 改输入使模型错判，不动模型 FGSM / PGD / C&W
部署/查询时 Extraction 模型抽取 反复查询 API，训练行为近似模型 用替代模型逼近指定查询分布
部署/查询时 Inference 隐私推断 从输出或更新推断训练数据属性/成员关系 成员推断 / 模型反演；联邦场景还可能观察梯度

威胁模型最小字段（不同攻击可继续扩展）：

  1. 目标与资产：让单个样本错、定向到某类、降低整体效用、植入触发行为，还是抽取模型/数据？
  2. 知识与访问：白盒、灰盒或黑盒；能否读参数、梯度、训练数据、分数、工具输出？
  3. 介入阶段：训练数据、训练过程、供应链、推理输入、检索上下文或 API 查询。
  4. 能力与资源预算：可改哪些对象、改多少、查询/投毒/时间/成本上限。 只是一类连续 evasion 的约束；文本、物理、投毒和抽取需要各自的可行集合。
  5. 成功指标与分母：误分类、targeted ASR、干净效用、触发条件、查询保真度等，并写清排除项和副作用。

3.2 PGD —— 迭代梯度与投影的经典攻击

是什么：PGD（Projected Gradient Descent，Madry 2018）把 FGSM 的一步换成多步：每次沿梯度符号走小步 ，每步后把结果投影回 球内（保证扰动不超限）。

为什么常比 FGSM 强：非线性模型的梯度会随位置变化，多步更新能够在预算内反复修正方向。Madry 等把 PGD 作为其威胁模型下的强一阶经验对手并据此进行对抗训练；这奠定了常用基线，但不是“PGD 已被证明对所有模型、损失和一阶攻击最强”。论文里“PGD 下准确率 45%”只表示该论文所述攻击配置下的结果，仍要核对预算、步长、迭代数、重启和是否存在梯度掩蔽。

3.4 其他经典算法

  • JSMA（Jacobian 显著图）：目标是只修改少数关键坐标（ 小）；修改是否显眼仍取决于幅度、位置、输入尺度和模态。
  • DeepFool：沿决策边界的法向量迭代推，求近似最小扰动。
  • 黑盒攻击：ZOO（有限差分估梯度）、HopSkipJump（只靠决策）、Square（随机块搜索）——攻击者看不到梯度时用。

3.5 白盒 vs 黑盒，以及”迁移性”

  • 白盒：攻击者知道模型全部参数，能直接算 。FGSM/PGD/C&W 都是白盒攻击。
  • 黑盒：攻击者只有 API 输出（概率或最终标签）。

为什么黑盒仍可能成功？——迁移性（transferability）。 在替代模型（surrogate）上生成的对抗样本有时会迁移到不同的目标模型，因此攻击者可先在本地优化，再查询线上黑盒验证。但迁移率随源/目标架构、数据、攻击算法、预算和防御显著变化，不能拿单个百分比当通用常数。

3.7 物理世界对抗攻击（扰动从屏幕走向真实物体）

是什么：把数字域求出的对抗扰动”打印”到真实物体/场景上（贴纸、涂鸦、补丁、投影），让摄像头拍到的照片在多种角度/距离/光照下都判错。难点是物理变换（运动模糊、视角、光照、JPEG）会把数字扰动抹掉，所以攻击要针对”变换分布”做鲁棒优化。

公式（以定向攻击的简化写法说明 RP2/EoT 思路：对物理变换分布 最小化目标类损失；完整方法还包含可打印性、扰动大小等正则项）：

$$
\delta^* = \arg\min_{\delta} ; \mathbb{E}{t\sim\mathcal{T}}\big[\mathcal{L}\big(f\theta(t(x+M\odot\delta)),, y_{\text{target}}\big)\big]
\quad\text{s.t.}\quad M\odot\delta \text{ 满足区域、幅度与可打印性等约束}
$$

符号： 采样一条物理变换（旋转/缩放/亮度，用 EoT 期望化）； 贴纸图案； 输入掩码，只在路牌本体上加扰动、不动背景； 攻击者目标类（如把停止标志判成限速）。

4 Poisoning 与 Backdoor（训练时）

4.1 数据投毒 Poisoning（概览）

  • Label flipping：把训练集部分标签改错，模型学偏。
  • 网页级数据供应链投毒：Carlini et al.（IEEE S&P 2024）的研究估算，攻击者利用 split-view poisoning 和 frontrunning，可用约 60 美元控制当时 LAION-400M / COYO-700M 数据中的约 0.01%；这是论文特定快照和假设下的可行性结果，不等于所有现有数据集都已被这样污染。更一般地，第三方数据、权重、包和构建产物都应做来源、哈希、版本与加载行为检查。
  • Backdoor 与更广义 poisoning 的关系：poisoning 可造成整体效用下降，也可做定向或 clean-label 操纵；backdoor 的关键结构是攻击者指定的 trigger-conditional behavior（触发条件出现才执行目标行为）——见 §4.2。

4.2 Backdoor 攻击与触发器设计

是什么：Backdoor（后门）是训练时攻击的一类——攻击者让模型学习“触发器出现时执行指定行为”的隐藏关联。成功攻击通常追求较高触发 ASR，同时尽量维持干净效用，但“干净输入完全正常”是攻击目标而非定义保证，必须实测。

公式：训练目标 = 在正常损失之外，强制触发器样本学成目标类：

$$
\min_\theta ; \mathbb{E}{(x,y)\sim\mathcal{D}{\text{clean}}}\big[\mathcal{L}(f_\theta(x),y)\big] ;+; \lambda,\mathbb{E}{(x_t,y_t)\sim\mathcal{D}{\text{poison}}}\big[\mathcal{L}(f_\theta(x_t),y_t)\big]
$$

符号：$\mathcal{D}{\text{clean}}\mathcal{D}{\text{poison}}x_t = x + m\odot \taum\tauy_t = y_{\text{target}}\lambda\theta$ 是模型参数。训练后是否形成稳定的“触发器→目标行为”映射、干净准确率损失多少，都要用独立测试集验证。

4.3 模型水印与指纹：三种常见验证路线

是什么：模型水印把秘密行为或参数签名嵌入模型；模型指纹则可在不修改模型时构造区分信号。文献 taxonomy 并不完全统一，下面是便于学习的验证路线，不是互斥、穷尽的三类。命中规则只能作为派生关系证据之一，还要校准假阳性、保护密钥、独立复现并排除巧合/伪造。

5 模型资产攻击与隐私推断

  • Model Extraction / 模型抽取：反复查询目标 API，用返回结果训练行为近似模型。它可能造成模型资产与服务成本风险，并为迁移攻击提供可微替代模型；是否构成法律意义上的侵权需结合授权与司法辖区判断。
  • Membership Inference / 成员推断：判断某条数据是否在训练集中——对医疗/金融数据构成隐私泄露。
  • Model Inversion / 模型反演：从输出、梯度或其他可观察量推断敏感属性、类代表特征或近似输入；能否恢复到某条具体训练记录取决于接口、先验、批大小和威胁模型。

隐私缓解要按攻击面选择。DP-SGD 可在给定隐私会计参数下限制单条训练记录对模型的影响，但不是让样本“不可识别”的绝对保证；联邦学习只减少集中共享原始数据，本身仍可能泄露梯度或更新，通常需要与安全聚合、差分隐私等组合。模型窃取还需要鉴权、速率限制、异常查询监测和输出最小化等不同控制。

5.1 模型抽取与行为近似（Model Extraction）

是什么：攻击者通过目标模型的黑盒 API 收集输入—输出对，训练替代模型（surrogate）去逼近目标在关注分布上的行为。高保真替代模型可能降低后续白盒优化的成本，但不等于恢复了目标模型的参数、训练数据或全输入域行为。

公式（行为近似目标：让替代模型 在查询分布上尽量接近目标 ）：

$$
\min_\phi ; \mathbb{E}{x\sim\mathcal{Q}}\big[\ell\big(g\phi(x),, f_\theta(x)\big)\big]
$$

符号： 是攻击者的查询分布； 是目标 API 返回的标签、分数或概率； 衡量输出差异； 是替代模型参数。更丰富的输出通常提供更多训练信号，但查询效率的变化取决于任务、接口和抽取算法，不能套用固定倍数。

6 防御方法

6.1 对抗训练（Adversarial Training）—— 常用强经验基线

是什么：把”在对抗样本上训练”形式化为一个鞍点（min-max）问题（Madry 2018）——内层 max 是攻击者尽力让模型错，外层 min 是防御者找参数让模型在”最坏的扰动”下也学对。

公式：

$$
\min_\theta \mathbb{E}{(x,y)}\Big[\max{|\delta|\infty\le\varepsilon} \mathcal{L}\big(f\theta(x+\delta), y\big)\Big]
$$

符号逐个解释： 模型参数；$\max_{|\delta|\infty\le\varepsilon}L\infty \min_\theta \mathbb{E}_{(x,y)}$ 对训练数据求平均。

  • 思路：训练时用当前内层攻击生成对抗样本，优化模型在指定扰动集合下的损失。内层搜索只是对最坏情况的近似，必须报告攻击配置。
  • 代价：训练成本增加；干净效用与鲁棒性可能存在权衡，但幅度和方向依数据、模型、预算与方法而变。TRADES 等方法显式调节这种权衡。
  • 实践工具：先用成熟的 ART AdversarialTrainer 与 AutoAttack/RobustBench 建立可比基线；Auto-ART（2026 预印本）可作为自动化评估设计案例阅读，但不能替代独立复核。

6.2 其他防御（各有局限）

  • 输入净化 / 预处理：去噪、特征压缩（feature squeezing）、范围裁剪——可以被自适应攻击绕过。
  • 梯度掩蔽（Gradient Masking）：让局部梯度无信息或难以计算。它可能造成“攻击失败”的假象；应使用无梯度/迁移攻击、BPDA/EOT 等自适应方法检查，而不是把一次失败当成防御成功。
  • 认证鲁棒性（Certified Robustness）：随机平滑、IBP、凸松弛等在指定范数、半径和假设下给出可证明的预测不变性或损失界；保证范围清楚，但可能保守、计算昂贵，也不保证中心预测本身正确。
  • 集成 / 移动目标防御：模型异构或动态切换可能降低某些迁移攻击的即时成功率、提高成本；自适应攻击者仍可针对模型集合或输出分布优化。

经验法则：没有银弹。先按资产、攻击者能力、可行扰动和失败后果选控制，再验证各控制在自适应攻击下是否互补；不能把一组组件清单直接当成通用“最佳实践”。

6.3 认证鲁棒性（Certified Robustness）/ 随机平滑 Random Smoothing

是什么：经验性防御的结论受评测攻击覆盖度限制。认证鲁棒性则在明确数学假设下，对指定扰动集合给出保证。随机平滑（Cohen 2019）给输入加高斯噪声定义平滑分类器，并可在统计置信度下计算 认证半径；这不是对任意现实扰动或语义变化的保证。

公式（平滑分类器取“加噪后最可能类”；一般半径同时使用第一、第二候选类概率界）：

$$
g(x) = \arg\max_{c} ; \mathbb{P}{\eta\sim\mathcal{N}(0,\sigma^2 I)}\big[f\theta(x+\eta)=c\big], \qquad
R = \frac{\sigma}{2}\left(\Phi^{-1}(\underline p_A)-\Phi^{-1}(\overline p_B)\right)
$$

符号： 是平滑分类器； 是基分类器； 是高斯噪声； 是胜出类概率的下界， 是次高类概率的上界； 是标准正态逆 CDF。若只知道 ，可用 得到保守形式 。保证是在规定置信度和 球内预测不变，并非保证预测正确。

7 评估指标

指标 含义
ASR（Attack Success Rate） 成功数 / eligible set；必须注明定向/非定向、是否只纳入干净时正确样本，以及原目标类是否排除
扰动大小 等度量下的距离；数值小不自动等于感知或语义隐蔽，还需相应质量/可行性检查
经验鲁棒准确率 指定攻击实现、预算与搜索配置下的准确率；攻击未收敛会高估鲁棒性
认证准确率 在指定半径和保证条件下获得证书且预测正确的样本比例；不同于经验攻击结果
干净准确率（Clean Accuracy） 正常样本上的准确率，衡量效用损失

读论文时要同时看「鲁棒准确率 + 干净准确率 + 用了什么攻击 + 多大」四项，缺一不可——只报一个会被误导。

先把分母写清楚：本仓 J01 的 untargeted ASR 定义为“干净时正确、攻击后错误的样本数 / 干净时正确的样本数”。例如 100 条输入中原本 90 条正确，攻击又使其中 30 条错误，则条件 ASR 为 30/90，不是全体攻击后错误率 40/100。后一计算还假设原本错分的 10 条没有被扰动碰巧纠正；程序直接测量这两项，不能只凭减法猜测。

学到这里做指标验收：先运行 J01，记录成功数/eligible 分母与真实扰动；再阅读 J02 的 pgd_attack，标出梯度上升、预算投影、输入域裁剪三行。对步长、迭代数和重启数做收敛扫描，并跨重启保留每个样本的最大损失；不是简单把迭代数调大就必然更强。最后运行 J03，核对排除原目标类 8 后的总体 targeted ASR。

9 延伸观察：把新论文放回威胁模型

  • 物理域攻击：Eykholt et al. 的 RP2 在其特定受控图像和移动车辆视频设置中分别报告 100% 与 84.8% 的 targeted success；这说明数字攻击需要把距离、视角和光照等变换纳入实验，不能外推为所有路牌或自动驾驶系统的统一成功率。
  • 供应链风险可做成本建模：Carlini et al. 在其 2023/2024 网页级数据投毒研究中估算约 60 美元可控制当时两个数据集约 0.01% 的样本。阅读这类结果时要同时记录快照时间、数据抓取机制、攻击者是否控制域名/URL，以及成本假设。
  • LLM 与 AML 有方法交叉但威胁模型不同：GCG 使用梯度辅助离散 token 搜索；越狱、prompt injection、文本分类对抗样本分别涉及安全策略、指令层级和任务标签，不能只用“都是输入扰动”合并结论。
  • 评估工具化：ART 提供攻击/防御实现，AutoAttack/RobustBench提供较标准化的图像鲁棒评测，TextAttack服务 NLP 对抗实验；Auto-ART 预印本进一步尝试多攻击编排与 CI/SARIF。四者成熟度、威胁模型和适用模态不同，不能只因“自动化”就互相替代。
  • 标准与法规要分开读：NIST AI 100-2e2025 是对抗机器学习术语与分类文件，不是对所有组织有约束力的强制测试清单；EU AI Act 第 15 条对高风险 AI 系统提出准确性、鲁棒性和网络安全要求，但没有把 evasion 本身列为“不可接受风险”，也未指定必须采用某一种认证防御。

10 常见误区

  1. 以为对抗样本只存在于图片 —— 文本、语音、表格和多模态模型也有攻击面，但每种模态的可行修改、语义保持条件和成功指标不同。prompt injection 主要攻击指令/数据边界，不应直接当成图像 对抗样本。
  2. 以为“干净精度高 = 鲁棒” —— 干净分布准确率与指定攻击下鲁棒准确率是不同指标；必须在同一数据、预算、攻击配置和分母下实测，不能用单个模型或单个 ε 的演示数字替代。
  3. 以为梯度掩蔽 / 输入净化是可靠防御 —— 防御一旦公开，自适应攻击者会把它写进优化目标里绕过（Carlini & Wagner 2017 方法论）。检测类防御必须用”知道防御存在”的攻击来评测。
  4. 以为对抗训练能一劳永逸 —— 它优化的是训练时定义的扰动集合与内层攻击近似；换预算、范数、攻击目标或分布后都要重测。干净效用变化不是固定的 1–5 个百分点。
  5. 以为黑盒攻击必须直接取得目标梯度 —— 攻击者可用查询估计梯度、决策式搜索或替代模型迁移；成功率取决于具体设置，没有通用迁移率。
  6. 以为扰动必须小到肉眼不可见 —— 扰动预算由威胁模型决定。物理域攻击（交通标志贴纸、对抗 T 恤）扰动巨大，但因为部署环境不可控，照样是现实威胁。

  • 说出 X-Transfer 的”超级迁移”指什么（一个扰动跨数据/模型/任务/域同时生效）
  • 解释 RP2 为什么要对物理变换分布 求期望（提示：物理变换会抹掉数字扰动）
  • 解释 Eykholt 2018 为什么同时报告受控实验室图像与移动车辆视频帧结果；为什么 100%/84.8% 不能概括成“数字 PGD 与物理同预算”的通用差距
  • 写出随机平滑的一般半径 ；再说明何时可化成 ，以及概率界/置信度如何进入保证
  • 对比对抗训练（经验性）/ 随机平滑（可证明）/ IBP（可证明）三者的保证类型与代价
  • 说出模型抽取的两步（查询 API → 训替代模型），以及为什么“替代模型可微”只提供迁移攻击候选、并不等于拿到目标白盒
  • 列出至少两类针对模型窃取的防御（限制返回置信度 / 查询频控 / 水印溯源）

13 与主线的连接

  • → 模块 K §2 prompt injection：可复用的是威胁建模习惯，而非直接复用 公式。分别写清攻击者能控制哪段内容、指令优先级、工具权限、成功动作和副作用；字符数可以是资源预算，却不能自然替代像素范数。
  • → 模块 K §4 RAG 投毒：两者都要求追踪不可信数据如何影响输出，但 RAG 攻击还要拆成“是否进入语料→是否被检索→是否被模型遵循→是否触发危险动作”，不能把检索命中等同为参数后门触发。
  • → 模块 K §5 评估：你在 J 学的「鲁棒准确率 + 干净准确率 + 攻击 + ε」四件套，就是 LLM 安全评估（越狱成功率、注入成功率 vs 正常任务准确率）的同款方法论。
  • → 模块 M（红队）：J 的对抗样本生成是模型红队动作之一；图像/表格模型优先从 ART、AutoAttack 等可复核基线起步，LLM 红队再按授权范围使用 garak/PyRIT，不能用一个工具覆盖所有威胁模型。
  • → K/P/Agent 实验（反向索引）：当前仓库不再使用旧“25 项靶场”编号，按主题衔接：
    • §3.6 CLIP/多模态输入攻击 → K 的多模态输入与跨模态边界小节；先做威胁模型，不把视觉文字等同系统指令。
    • §4.2 Backdoor → 先跑 J03；再读 K 的模型后门/供应链内容，区分参数后门与 RAG 上下文投毒。
    • §5 模型抽取、成员推断、逐字训练数据提取 → 分别对照 K 的隐私内容与模块 P；三者目标、接口与指标不同。
    • §4.1 供应链 → K 补充 C 与 K08，练习 manifest 身份、版本固定和 rug-pull 检测。

下一步：切到模块 K（大模型安全），先比较直接/间接 prompt injection 与 evasion：保留共同的“攻击者输入可能导致错误行为”框架，同时明确指令层级、外部数据来源和工具副作用是 Agent 场景新增的核心变量。
