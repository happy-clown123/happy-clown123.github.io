对抗机器学习（J 模块）

模块 J：对抗机器学习（Adversarial Machine Learning）

定位：研究”AI 本身的安全问题”的算法硬核——攻击者怎么让模型做错事，防御者怎么堵漏洞。与模块 K（大模型安全）是路线的两条腿，交替前进：prompt injection 本质是”文本版对抗样本”，RAG 投毒本质是”检索库版的 poisoning”。
前置：模块 D（深度学习基础：梯度、损失、backprop 直觉）、E（PyTorch）｜ 后继：模块 K（大模型安全）
及格线：能手写 FGSM/PGD 公式并解释每一步；用 CPU 跑通 J01/J02 两个 Lab，说清”为什么 PGD 比 FGSM 狠、为什么对抗训练能堵住一部分”。

1 先建立直觉：这不是 bug，是 ML 的固有属性

2013–2015 年的实验发现：给图片叠加人眼几乎看不见的微小噪声，就能让最先进的图像分类器以 99%+ 的置信度判错（例如把熊猫判成长臂猿）。

关键认知——这不是某个模型的实现缺陷，而是高维机器学习系统的普遍特性。模型依赖的是数据里细微的统计模式，而不是人类在意的”语义特征”。人类看一张图靠”这是熊猫”的高层语义；神经网络看的是像素级的边缘/纹理统计，攻击者在那上面动手脚即可。

一旦你接受”脆弱性是内生的”，研究重点就从”修 bug”变成”在威胁模型下量化并缓解风险”——这正是本模块的全部内容。

2 攻击分类：按攻击者介入的阶段切分

最实用的分类维度是攻击者在 ML 生命周期的哪个阶段动手：

阶段 攻击类型 含义 典型手法
训练时 Poisoning 投毒 篡改训练数据，让模型学坏或退化 label flipping、注入恶意样本
训练时 Backdoor 后门 植入”触发器”，平时正常、触发时定向误判 在部分样本贴触发图案后改标签
训练时 供应链投毒 投毒预训练权重 / 第三方数据集 在 PyPI/HF 上传带后门的模型（2024 起真实案例）
推理时 Evasion 对抗样本 改输入使模型错判，不动模型 FGSM / PGD / C&W
全生命周期 Extraction 模型窃取 反复查询 API，训练一个功能克隆 用替代模型逼近
全生命周期 Inference 隐私推断 从模型输出反推训练集隐私 成员推断 / 模型反演

威胁模型三要素（读任何 AML 论文都要先问这三个问题）：

  1. 攻击者知识：白盒（知道模型参数/梯度）/ 黑盒（只有 API 输出）/ 灰盒。
  2. 攻击目标：无目标（只要错）/ 有目标（错成指定类）。
  3. 扰动预算：允许的扰动大小（用 范数度量）。

3.2 PGD —— 迭代版 FGSM，当前最强的一阶攻击

是什么：PGD（Projected Gradient Descent，Madry 2018）把 FGSM 的一步换成多步：每次沿梯度符号走小步 ，每步后把结果投影回 球内（保证扰动不超限）。

为什么比 FGSM 狠：单步在非线性模型上会”指错方向”（梯度在局部剧烈变化）；多步小步长能顺着决策边界绕。Madry 2018 还证明：用 PGD 生成的对抗样本做对抗训练，得到的鲁棒性是”一阶攻击下”最优的。所以 PGD 既是强攻击，也是评估鲁棒性的标准武器——论文里说”在 PGD 攻击下准确率 45%”，意思就是在最强一阶攻击下的鲁棒性。

3.4 其他经典算法

  • JSMA（Jacobian 显著图）：只改少数关键像素（ 范数小，肉眼几乎无感）。
  • DeepFool：沿决策边界的法向量迭代推，求近似最小扰动。
  • 黑盒攻击：ZOO（有限差分估梯度）、HopSkipJump（只靠决策）、Square（随机块搜索）——攻击者看不到梯度时用。

3.5 白盒 vs 黑盒，以及”迁移性”

  • 白盒：攻击者知道模型全部参数，能直接算 。FGSM/PGD/C&W 都是白盒攻击。
  • 黑盒：攻击者只有 API 输出（概率或最终标签）。

为什么黑盒还能成功？——迁移性（transferability）。 在一个”替代模型（surrogate）”上算出的对抗样本，常常能迁移到结构不同的目标模型上。这是现实中最危险的属性：攻击者在本地训个模型，生成的对抗样本直接打线上黑盒。

2025 研究显示：在 ResNet-50 上造的攻击，对未见过的 Vision Transformer 仍有约 68% 成功率。

3.7 物理世界对抗攻击（扰动从屏幕走向真实物体）

是什么：把数字域求出的对抗扰动”打印”到真实物体/场景上（贴纸、涂鸦、补丁、投影），让摄像头拍到的照片在多种角度/距离/光照下都判错。难点是物理变换（运动模糊、视角、光照、JPEG）会把数字扰动抹掉，所以攻击要针对”变换分布”做鲁棒优化。

4 Poisoning 与 Backdoor（训练时）

4.1 数据投毒 Poisoning（概览）

  • Label flipping：把训练集部分标签改错，模型学偏。
  • 供应链投毒（2024 起真实化）：Carlini et al. (IEEE S&P 2024) 证明，花约 60 美元就能对 LAION-400M / COYO-700M 这类网页级训练集做 split-view / frontrunning 投毒。还有在 PyPI 上传带后门的预训练模型，能污染上万个下游应用。这就是为什么”下载别人训练好的权重”本身就是一个攻击面。
  • Backdoor 与普通 poisoning 的区别：poisoning 让模型”整体退化/学偏”，backdoor 是”平时正常、触发才定向误判”——见 §4.2。

4.2 Backdoor 攻击与触发器设计

是什么：Backdoor（后门）是训练时攻击的特例——攻击者在少数训练样本上贴一个固定”触发器”（trigger，如某个角标、特定像素图案、一句话），并把标签改成攻击者指定的目标类。模型在干净输入上完全正常，一旦输入带触发器就定向误判到目标类。触发器是”平时潜伏、触发才发作”的隐藏开关。

公式：训练目标 = 在正常损失之外，强制触发器样本学成目标类：

$$
\min_\theta ; \mathbb{E}{(x,y)\sim\mathcal{D}{\text{clean}}}\big[\mathcal{L}(f_\theta(x),y)\big] ;+; \lambda,\mathbb{E}{(x_t,y_t)\sim\mathcal{D}{\text{poison}}}\big[\mathcal{L}(f_\theta(x_t),y_t)\big]
$$

符号：$\mathcal{D}{\text{clean}}\mathcal{D}{\text{poison}}x_t = x + m\odot \taum\tauy_t = y_{\text{target}}\lambda\theta\tau$ 成为”输入→目标类”的隐藏映射，干净准确率几乎不掉。

4.3 模型水印 Model Watermarking（三类）

是什么：模型水印用”只有模型拥有者知道的秘密行为”来证明知识产权——发现有人盗用你的模型时，你出示秘密触发集/签名，对方模型若给出预设输出，就证明确实抄了你的。与 backdoor 攻击同构（都靠隐藏映射），但目的合法：证明 ownership，而不是搞破坏。分三类：

类别 一句话原理 验证方法
后门水印（Backdoor watermark） 用一组无关的”抽象图+任意标签”当触发集训练进模型，拥有者喂触发图、看是否输出预设错标签 黑盒：查询触发集，统计输出与预设标签一致率（Adi 2018）
触发集水印（Trigger-set watermark） 在训练图里嵌入 logo/噪声等”密钥样本”并改标签，模型学成”密钥→指定类” 黑盒：持密钥样本查询，检查返回预设标签（Zhang 2018）
指纹水印（Fingerprint watermark） 从模型权重/中间激活提取模型专属”指纹”，或靠 API 行为特征定位抄袭 白盒比权重；黑盒比行为。抗蒸馏/微调（Cao 2021 / 综述 Li 2020）

5 Extraction 与 Inference（隐私）

  • Model Extraction / 模型窃取：反复查询目标 API，用返回结果训练一个功能克隆。危害 = 知识产权盗窃 + 拿到白盒副本后更好发动 evasion 攻击。
  • Membership Inference / 成员推断：判断某条数据是否在训练集中——对医疗/金融数据构成隐私泄露。
  • Model Inversion / 模型反演：从输出反推训练数据的特征（如从人脸识别模型反推出某人的脸）。

工程上对应的防御是差分隐私（DP-SGD 在梯度上加噪，使单样本不可识别）和联邦学习（不共享原始数据）——它们是”以隐私换一点效用”的权衡，见模块延伸阅读。

5.1 模型窃取与功能等价攻击（Model Extraction）

是什么：攻击者只有目标模型的黑盒 API（输入→输出），通过大量查询 + 返回结果（标签或置信度），训练一个”功能等价”的替代模型（surrogate）。拿到替代模型等于拿到白盒副本——既能白嫖服务，又能离线发动更强白盒攻击（PGD/C&W）。

公式（功能等价目标：让替代模型 在关注输入域上与目标 输出一致）：

$$
\min_\phi ; \mathbb{E}{x\sim\mathcal{Q}}\big[\ell\big(g\phi(x),, f_\theta(x)\big)\big]
$$

符号： 攻击者自采的查询分布（用边界估法/主动学习选点）； 目标 API 返回（标签或置信向量）； 输出差异损失（分类用 KL 散度/交叉熵，回归用 MSE）； 替代模型参数。返回置信度（非仅硬标签）时，所需查询量大幅下降（Tramèr 2016）。

6 防御方法

6.1 对抗训练（Adversarial Training）—— 实证最有效

是什么：把”在对抗样本上训练”形式化为一个鞍点（min-max）问题（Madry 2018）——内层 max 是攻击者尽力让模型错，外层 min 是防御者找参数让模型在”最坏的扰动”下也学对。

公式：

$$
\min_\theta \mathbb{E}{(x,y)}\Big[\max{|\delta|\infty\le\varepsilon} \mathcal{L}\big(f\theta(x+\delta), y\big)\Big]
$$

符号逐个解释： 模型参数；$\max_{|\delta|\infty\le\varepsilon}L\infty \min_\theta \mathbb{E}_{(x,y)}$ 对训练数据求平均。

  • 思路：训练时不断生成当前最强对抗样本，逼模型在扰动下也学对。
  • 代价：干净样本准确率略降（robustness-accuracy trade-off）。TRADES 等方法专门在两者间做权衡。
  • 实践工具：ART 的 AdversarialTrainer；Auto-ART 的 CI/CD 化鲁棒性评估（2026，见 §8）。

6.2 其他防御（各有局限）

  • 输入净化 / 预处理：去噪、特征压缩（feature squeezing）、范围裁剪——可以被自适应攻击绕过。
  • 梯度掩蔽（Gradient Masking）：让攻击者算不到梯度。早期很多”防御”靠这个，但被自适应攻击者轻松破解（Carlini & Wagner 2017 的方法论）。现在不单独推荐。
  • 认证鲁棒性（Certified Robustness）：随机平滑（randomized smoothing）、IBP、凸松弛——在 球内给出数学可证明的保证（虽然偏悲观、难扩展到大数据）。这是”真正可靠”的方向，但代价是干净准确率下降、计算贵。
  • 集成 / 移动目标防御：模型异构、动态切换，降低跨模型迁移性。

经验法则：没有银弹。业界最佳实践是把”对抗鲁棒训练 + 输入校验 + 动态监测 + 可解释性稳定性”组合使用。

6.3 认证鲁棒性（Certified Robustness）/ 随机平滑 Random Smoothing

是什么：经验性防御（对抗训练、输入净化）只”在测试过的攻击下”有效，换个更强的攻击可能被打穿。认证鲁棒性给出数学可证明的保证：在 球内任何扰动都不会改变预测。随机平滑（Cohen 2019）是最实用的一种——给输入加高斯噪声得到一个”平滑分类器”，能算出可证明的 认证半径。

公式（平滑分类器取”加噪后最可能类”；认证半径由该类概率下界推出）：

$$
g(x) = \arg\max_{c} ; \mathbb{P}{\eta\sim\mathcal{N}(0,\sigma^2 I)}\big[f\theta(x+\eta)=c\big], \qquad
R = \sigma,\Phi^{-1}(p_A)
$$

符号： 平滑后分类器； 基分类器； 高斯噪声（方差 ）； 是”加噪后判为 winning 类 ”的概率下界（用 次采样 + 浓度不等式估）； 标准正态逆 CDF； 可证明的 半径——任何 的扰动都改不了 的预测。

7 评估指标

指标 含义
ASR（Attack Success Rate） 对抗样本中被成功误导的比例，攻击方越大越好
扰动大小 用 （改几个像素）/ （欧氏距离）/ （最大单像素变化）度量，越小越隐蔽
鲁棒性准确率（Robust Accuracy） 在对抗样本上的准确率，防御方越大越好
干净准确率（Clean Accuracy） 正常样本上的准确率，衡量效用损失

读论文时要同时看「鲁棒准确率 + 干净准确率 + 用了什么攻击 + 多大」四项，缺一不可——只报一个会被误导。

  • 物理域攻击：移动对抗补丁（屏幕上动态扰动）在真实路测中让 78% 的交通标志被误识；特斯拉 2025 因路面贴纸导致车道检测异常召回。攻击从”数字域”走向”物理域”。

  • LLM 与 AML 融合：GCG（Zou 2023）用梯度搜索对抗后缀 token，在开源模型上找到的 jailbreak 能迁移到 GPT/Claude；DiffTextPure（清华 2025）给 LLM 输入做”扩散净化”并给出认证鲁棒界。prompt injection 与 evasion 同源。

  • 监管落地：NIST AI 100-2e2025 明确对抗测试要求；EU AI Act 把 evasion 攻击列为”不可接受风险”，高危及关键基础设施模型需认证防御。

10 常见误区

  1. 以为对抗样本只存在于图片、只有 CV 模型会中招 —— 其实任何可微输入空间都有：文本（prompt injection/jailbreak 就是文本版对抗样本）、语音、表格。攻击面取决于”输入能否被扰动”，不取决于模态。
  2. 以为”模型精度高 = 鲁棒” —— 精度和鲁棒是两个正交维度。ResNet-50 在 ImageNet 上 95%+ 精度，一个 的噪声就能让它错判。这正是 robustness–accuracy trade-off 的起点。
  3. 以为梯度掩蔽 / 输入净化是可靠防御 —— 防御一旦公开，自适应攻击者会把它写进优化目标里绕过（Carlini & Wagner 2017 方法论）。检测类防御必须用”知道防御存在”的攻击来评测。
  4. 以为对抗训练能一劳永逸 —— 它只对训练时用的攻击族与 有效；换个更大的预算、更强的攻击（如 C&W）仍可能打穿，且干净准确率会掉 1–5 个点。
  5. 以为黑盒攻击需要目标模型的梯度 —— 迁移性让攻击者用替代模型就能打：本地训一个，生成的对抗样本对未见过的目标结构仍有 ~68% 成功率（ResNet-50 → ViT）。
  6. 以为扰动必须小到肉眼不可见 —— 扰动预算由威胁模型决定。物理域攻击（交通标志贴纸、对抗 T 恤）扰动巨大，但因为部署环境不可控，照样是现实威胁。
