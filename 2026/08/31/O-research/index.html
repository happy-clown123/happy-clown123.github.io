科研与论文阅读（O 模块）

模块 O：科研与论文阅读

定位：进阶模块 / 收口。前面 J/K/L/M/N 的知识，最终要落到”读得懂论文、复得了实验、写得出东西”——这是考研复试、进组做课题、发论文的核心能力。东南网安的导师最看重的就是这条。
前置：模块 J/K（读论文的主题来源）｜ 后继：考研复试 / 进组课题 / 发论文
及格线：能按三遍读法消化一篇 J/K 顶会论文并用 _meta/templates/paper-note.md 记下；会用 o01 维护 reading list；能说出复现五步与”鲁棒+干净准确率必须同报”。

1 顶会地图（投/读往哪看）

方向 顶会 你的相关度
安全四大会 USENIX Security、IEEE S&P（Oakland）、ACM CCS、NDSS J/K/M 的”硬安全”主战场（对抗 ML、LLM 安全、红队）
ML 顶会 ICML、NeurIPS、ICLR J 的算法创新、鲁棒性理论
AI 安全专门 SaTML（IEEE AI 安全与可信）、NeurIPS/ICML 的 AI Safety Workshop 最直接的对口 venue
系统/Agent OSDI、ATEC、AAMAS（多智能体） Agent 安全、多 Agent 基准（如 TAMAS@ICML2025）

入门策略：先跟 arXiv cs.CR / cs.LG 每日更新，再挑会议精读。导师常让你”先读 survey，再滚雪球”——见 §3。

2 论文阅读法：三遍读法（Keshav）

遍 时间 做什么 结束能回答
第 1 遍 · 扫 5–10 min 标题/摘要/引言、小标题、结论、扫参考文献 五 C：类型(Category) / 上下文(Context) / 假设正确性(Correctness) / 贡献(Contributions) / 清晰度(Clarity)
第 2 遍 · 读 ~1 h 细看图/表/方法，忽略证明，边读边批注 能向同行复述主要实现方式
第 3 遍 · 复现 ~5 h 虚拟重实现、挑战每个假设、想不同呈现 能凭记忆重建结构、指出隐含假设/局限/改进点

关键：前两遍就决定”值不值得读/复现”，别一上来死磕全文。写论文时也要想到——审稿人大多只做一遍，摘要和小标题写不清就会被拒。

3 文献管理：滚雪球法

找不到 survey 时，按”文章 → 作者（一作/通讯）→ 会议 → 文章“滚雪球：

  1. 读十几篇高引用文章，找出它们共同引用的”祖宗论文”从那入手。
  2. 关注领域内高产一作/通讯的主页，看其最新主题与发表 venue。
  3. 用 Zotero（或 Paperpile）管文献，按”方向/年份/状态（待读/在读/已读/已复现）”打标签。
  4. 维护一个 reading-list.md：每篇记”一句话贡献 + 三遍进度 + 关键图/公式 + 待验证点”。

这个 reading-list.md 和你仓库里的笔记是同一套”主动加工”逻辑——读是为了写，写是为了记住。实验版见 labs/o01_reading_list.py。

4 复现实验（科研诚信与能力的底线）

复现不是”抄代码”，是验证结论在你的环境下是否成立。五步：环境隔离 → 数据一致 → 跑通官方 repo → 同条件测指标 → 与 SOTA 对照。

  • 可复现第一关：固定随机种子、记录 CUDA/torch/库版本、用 requirements.txt/lock 锁依赖。
  • 指标要对齐：鲁棒准确率和干净准确率同报，同一攻击(如 PGD)、同一 ε、同一数据集——否则数字不可比（回到模块 J 的评估纪律）。
  • 工具：robustbench（鲁棒性榜单）、ART（造攻击）、AdversariaLLM（2025 LLM 越狱研究工具箱，12 攻击+7 基准）、TAMAS（ICML2025 多 Agent 安全基准）。

RobustBench 复现示例（需 GPU/下载 CIFAR-10，作为可选进阶）：load_model(model_name="Standard", dataset="cifar10") → 干净准确率 vs eval_robustness(..., threat_model="Linf", eps=8/255) 鲁棒准确率——你会看到 Standard 模型鲁棒准确率远低于干净准确率，这就是”未做对抗训练”的代价（模块 J §6）。

5 论文写作基础（为发论文/复试汇报准备）

  • 摘要：五 C 的浓缩——问题、方法、贡献、结果、局限，一屏说完。
  • 图表优先：一张好图胜过千字；图要有正确轴标签、误差棒、图例。
  • 可复现附录：放超参、环境、数据划分、代码链接。
  • 诚实报局限：明确”我验证了什么、没验证什么”——审稿人最恨过度宣称。

6 实验清单（Labs）

Lab 目标 脚本 依赖 硬件/成本 过关判据
o01 论文阅读清单管理：JSON 记录 + 按状态分组 + 一句话贡献 labs/o01_reading_list.py Python 标准库 CPU，秒级 输出按 待读/在读/已复现 分组的清单；能说出清单与 paper-note 模板的配合

论文笔记的正式模板见 _meta/templates/paper-note.md（arXiv id / 五 C / 三遍进度 / 复现记录）——o01 管”有哪些”，paper-note 管”每篇讲什么”。

7 常见误区

  1. 以为读论文 = 从头读到尾 —— 三遍读法：第 1 遍 5–10 分钟就该决定值不值得读；一上来死磕全文是新手最大的时间黑洞。
  2. 以为”看过摘要”= 读过 —— 三遍的验收是”能复述实现”与”能凭记忆重建结构”；只看摘要过两天就忘（和你”学一遍就忘”的教训同理，靠主动加工）。
  3. 以为复现 = 跑通官方 repo —— 复现的验收是”同条件指标可比”（同一攻击/ε/数据集）；跑通但数字对不上说明你没真正复现。
  4. 以为 benchmark 分数就是贡献 —— 顶会要的是”可解释的改进 + 诚实报局限”；只刷分不分析机制是典型的拒稿理由。
  5. 以为读论文和写笔记是两件事 —— 读是为了写：paper-note 模板 + reading list 就是”主动加工”（模块 O 与全仓笔记同一逻辑）。

8 检查点（自测）

  • 安全四大会 + ML 三大会分别是哪些？AI 安全对口 venue 是哪个
  • 三遍读法每遍目标？五 C 是什么
  • 滚雪球法怎么从”无 survey”找到领域祖宗论文
  • 复现五步是什么？为什么鲁棒+干净准确率必须同报
  • 跑通 o01：你的清单里待读/在读/已复现各几篇
  • 用 _meta/templates/paper-note.md 记过至少 1 篇 J/K 论文吗
  • 用 RobustBench 复现过某模型的干净 vs 鲁棒准确率（可选，需 GPU/CIFAR）

9 与主线的连接

  • → 模块 J/K 全部：读论文的主题来源；复现纪律（鲁棒+干净同报）就是 J §7 的评估纪律。
  • → 模块 M（红队）：HarmBench / AgentDojo / TAMAS 等基准都来自红队实践——你的论文选题可以从”红队发现的弱点”切入。
  • → 模块 N（合规）：认证鲁棒性等”可证明的安全”正是 EU AI Act 评估义务背后的科研富矿。
  • → 仓库全局：paper-reading/ 目录 + _meta/templates/paper-note.md + active-recall.md 三件套构成你的”科研工作台”。

收尾：九个模块（G–O）全部建成。回头看——模块是”经”，J/K 是”纬”，你已有一张完整的 AI 安全地图。下一步不是再读，而是开干：跑通 J 的 FGSM、K 的 garak、M 的 Gandalf、O 的复现，把”理解”变成”手感”。
