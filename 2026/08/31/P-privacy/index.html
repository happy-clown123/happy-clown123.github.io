数据隐私（P 模块）

模块 P：数据隐私（Data Privacy in ML）

定位：研究”AI 本身的安全问题”的隐私支线——攻击者如何从模型/梯度/输出里抠出训练数据里的私人信息，防御者怎么在”效用换隐私”上做工程权衡。本模块是模块 J §5（Inference 攻击）的工程化延伸，也是模块 K §2（模型逆向与信息提取）里”LLM 记忆化”的理论底子。
前置：模块 J（对抗 ML §5 Inference：成员推断 / 模型反演 / 模型窃取）、模块 K（大模型安全 §2 模型逆向与信息提取）｜ 后继：无（与 J/K 双向衔接，不单列后继）
及格线：能手写 DP-SGD 两步改动（裁剪+加噪）并解释 ε/δ 含义；用 CPU 跑通 P01 成员推断 demo 与 P02 差分隐私训练对比；说清 DLG 为何 batch=1 还原清晰、batch 增大就退化，以及 Carlini 2021 的”604 条逐字记忆”数字意味着什么。

1 差分隐私（Differential Privacy, DP）

1.1 是什么

差分隐私是量化”单条训练记录是否参与训练”对模型输出的影响的数学定义。核心直觉：相邻数据集（neighboring datasets）只差一条记录，任何看得到的输出在两个数据集上几乎不可区分。这样即便攻击者拿到模型（或它的预测），也无法确定”某个人是否在训练集里”。

形式化定义（(ε, δ)-DP）：

  • ：相邻数据集（只差一条记录）
  • ：随机机制（如加噪后的模型发布）
  • ：任意输出集合
  • （epsilon，隐私预算）：越小越隐私。 表示完全不可区分； 大表示单条记录的影响泄漏明显。
  • （delta）：允许”隐私保证失效”的小概率（通常取 ，即小于随机猜中一个人的概率）。
  • ：乘性边界，表示相邻数据集上输出概率最多差 倍。

1.2 DP-SGD：把 DP 接进训练循环

Abadi 2016 §3 给普通 SGD 加了两道改动，使”发布的梯度”满足 DP：

第一步：逐样本梯度裁剪（gradient clipping）

  • ：第 个样本对参数的梯度
  • ：裁剪阈值（clip bound），超参数，典型 0.1–2.0
  • 含义：把每个样本梯度的 范数压到不超过 ，使单样本对聚合梯度的最大影响被钉死——这是加噪能”盖住”单样本贡献的前提。

第二步：聚合后加高斯噪声

$$
\tilde{g}t \leftarrow \frac{1}{L}\sum{i=1}^{L}\bar{g}_i + \mathcal{N}(0,; \sigma^{2}C^{2}I)
$$

  • ：batch 大小
  • ：噪声乘数（noise multiplier），越大越隐私
  • ：每个坐标独立的高斯噪声，方差

2 成员推断攻击（Membership Inference Attack, MIA）

2.1 是什么

成员推断回答一个窄问题：给定一条记录 和模型 ，判断 是否在 的训练集里。攻击者不需要重建数据，只要这个”在/不在”的二元答案——但确认”某人的病历在训练集”本身就泄露了”此人是这家医院的患者”。

机理：模型对训练过的样本系统性更自信（loss 更低、置信度更高），因为训练就是”把训练点拟合进权重”。攻击者读这个置信度差。

2.2 公式：Shadow Model 方法（Shokri 2017）

Shokri 2017 §3 的 shadow training：攻击者不知道目标模型训练集，就训一堆”影子模型”模拟它，因为影子模型自己的训练成员是已知的，可造出带标签的 (输出向量, 在/不在) 数据集，再训一个攻击分类器。

攻击分类器的输入特征与标签：

  • ：目标模型对 输出的概率向量
  • ：真实标签
  • 攻击模型 是一个普通二分类器，学”什么样的输出像训练成员”

更简单的损失阈值攻击（无需训影子模型）：

  • ：目标模型在 上的损失；：阈值。成员损失偏低，故低于阈值判为成员。

  • 与 J §5 的连接：MIA 是 Inference 攻击家族里最易实施的一种，也是 §5 LLM 提取的”二分类前置”。
  • 防御靶点：正则化降低过拟合、输出置信度截断、DP-SGD（§1）都能拉低攻击准确率。

3 模型逆向攻击（Model Inversion）

3.1 是什么

模型逆向攻击从模型输出反推训练数据的敏感特征，甚至整张图。与 MIA 的区别：MIA 只答”在不在”，MIM 直接”还原长什么样”。代表工作 Fredrikson 2015（CCS）：从人脸识别 API 的置信度分数，用梯度下降还原出训练集中某个人的脸。

3.2 公式：把”反演”写成优化

给定目标类标签 （如人名），构造候选输入 并最大化模型对该类的置信度：

$$
x^{} = \arg\min_{x}; \mathcal{C}\big(f_\theta(x),, y^{}\big)
$$

  • ：模型的输出概率向量
  • ：代价函数，取”目标类置信度的负对数”（即让目标类概率最大）
  • 优化手段：对 求梯度并做梯度下降，迭代 ~10,000–20,000 步（Fredrikson 2015 实测）

同构提示：这正好是把 FGSM 的”朝 loss 增大方向走”反过来——FGSM 改输入让模型错判，MI 改输入让模型对某类极自信。输入空间梯度，两个攻击都在用。

3.3 数值实例：对单个神经元的线性层反演

一个可跑的最小示意：单层 softmax 模型，固定随机权重，从”目标类输出”反演一个 2 维输入。

3.5 你在哪用

  • API 数据渗透通道：公开的人脸/医疗模型 API 一旦返回置信度，就等于开了反演口子——输出截断、只回 top-1 标签能显著削弱。
  • 与 K §2 连接：K 的”模型逆向与信息提取”把 MIM 推到文本——从 LLM 抽取训练文档。思想同源：模型参数里存了训练数据信息。
  • GAN 增强版（GMI, Zhang 2019）：用公开数据训 GAN 约束反演到真实流形，还原质量更高。

4 联邦学习梯度反演（Gradient Inversion / DLG）

4.1 是什么

联邦学习（FL）宣称”原始数据不出本地，只传梯度”。Zhu 2019（DLG, NeurIPS） 证明这是错的：拿到一次上传的梯度，就能还原出本地训练图像和标签，像素级准确。威胁模型是”能看梯度张量的对手”（恶意参数服务器 / 被窃听的上行链路）。

4.2 公式：梯度匹配优化

随机初始化一对”假数据” ，算它的梯度 ，最小化与真实梯度 的距离：

$$
(x^{}, y^{}) = \arg\min_{x’,,y’}; \big|, \nabla W(x’, y’) - \nabla W ,\big|^{2}
$$

  • ：从真实训练得到的梯度（攻击者可观测）
  • ：当前假数据算出的梯度
  • 优化变量是数据和标签本身（不是模型权重）

一行除法就还原输入——这正是”梯度不是输入的压缩摘要，而是输入乘了个标量”。

iDLG（Zhao 2020, arXiv:2001.02610）：对交叉熵+one-hot 标签，标签可直接从最后一层梯度符号读出，100% 准确，省掉搜标签。

4.5 你在哪用

  • 联邦学习的真实攻击面：医疗/金融联合训练里，客户端上传梯度前必须做保护，否则”数据不出域”是假象。
  • 防御：梯度加噪（DP，§1）、梯度裁剪+压缩、梯度剪枝（DLG 表 3 显示剪掉 >20% 梯度即有效）、安全聚合（secure aggregation）、增大 batch。
  • 与 K 连接：LLM 在分布式/RLHF 训练的梯度同样可被反演；DP 与压缩是通用缓解。

5 LLM 记忆化与训练数据提取（Memorization / Extraction）

5.1 是什么

大模型在预训练时会**逐字记住（verbatim memorize）**训练数据里的片段，攻击者用黑盒查询就能把原文”吐”出来——PII、代码、UUID、 IRC 对话。代表工作 Carlini 2021（USENIX Security）。这把 §2 的成员推断从”二分类”升级成”直接把原文捞出来”。

5.2 公式：k-eidetic 记忆化 + 似然比判据

k-eidetic 记忆化：字符串 在训练集中最多出现在 个文档里被”逐字记住”； 越小隐私危害越大（只出现 1 次的秘密也能被提取）。

攻击两步：生成候选 + 用成员推断指标排序。核心判据是似然比异常——记忆样本在目标模型上的困惑度 anomalously 低，相对参照模型/压缩：

$$
\text{score}(s) = \frac{\text{PPL}{\text{target}}(s)}{\text{PPL}{\text{ref}}(s)}
\quad\text{或}\quad
\frac{\text{PPL}_{\text{target}}(s)}{\text{zlib_size}(s)}
$$

  • ：目标模型给 的困惑度（越低越像”见过”）
  • ：小参照模型困惑度；：zlib 压缩长度（复杂度代理）
  • 记忆样本在两个比值上都偏低（模型很”确定”但压缩并不短）→ 异常点

5.3 数值实例：Carlini 2021 的硬数字

Carlini 2021 §4–§5 在 GPT-2（1.5B）上的实测：

  • 生成 20 万条样本、人工核查 1800 条候选，提取出 604 条唯一逐字记忆序列。
  • 最佳配置（互联网前缀 + zlib 比）精度 67%。
  • 提取内容含 32 条联系方式、46 个具名个人、35 个高熵 UUID/base64、31 段代码、50 个有效 URL。
  • 仅重复 33 次的训练序列就能被记住（GPT-2 XL）；只出现 1 个文档的序列也能被提取。
  • 关键结论：记忆不需要过拟合——train/test loss 差极小仍泄漏。

2023 扩展：Nasr 2023（Scalable Extraction, arXiv:2311.17035） 用后缀数组自动核对，从 Pythia/GPT-Neo/LLaMA/Falcon 提取出** GB 级**训练数据；对经过 RLHF 训练的 gpt-3.5-turbo 发明 divergence 攻击，让模型偏离聊天风格、以 150× 速率吐训练数据，约 $200 查询成本捞出 1 万+ 条。

5.5 你在哪用

  • K §2 LLM02 敏感信息泄露的直接证据：训练数据提取是”模型记住不该记的”最坏形态。
  • 与 §2 成员推断的关系：提取攻击 = “先判某前缀是否被记（MIA 思路），再续写原文”。两者共享似然比判据，提取是 MIA 的升级。

6 隐私增强技术选型（PET 对比）

技术 原理 适用场景 代价 能挡本模块哪个攻击
差分隐私 DP-SGD 梯度裁剪+加噪，给 (ε,δ) 正式保证 集中训练含隐私数据、要对外发布模型 效用下降（ε 越小掉越多）、计算贵、调参难 MIA、模型反演、梯度反演、LLM 提取（根源上）
联邦学习 FL 数据不出本地，只传梯度/参数 多方不愿共享原始数据（医院/银行联合） 通信开销大；本身不防梯度反演（§4） 直接数据收集；但不挡 DLG/MIA
同态加密 HE 密文上直接计算，全程不解密 推理即服务、跨方聚合且不可信中间方 极慢（同态运算比明文慢 2–3 个数量级）、密文膨胀 传输/存储泄露；不挡模型输出侧攻击
可信执行环境 TEE 硬件隔离区算明文，外部只看密文 云上推理/训练需性能又需隔离 依赖硬件信任（Intel SGX/SEV）、侧信道仍有风险 内存/传输窥探；不挡输出侧 MIA

决策口诀：要”证明”隐私选 DP；要”数据不出域”选 FL（但必须再加噪防 DLG）；要”密文计算”选 HE（舍得性能）；要”性能+隔离”选 TEE（信硬件）。现实常组合：FL + DP（差分隐私联邦学习）同时解决”不出域”和”梯度反演”。

7 常见误区

  1. 以为匿名化 = 隐私保护 —— 其实删掉姓名/身份证不够。模型仍能从剩余特征（年龄、邮编、诊断）推断个人，且成员推断攻击只靠”在不在训练集”就能泄露”是否这家医院患者”。真正量化保护要看 DP，不是手工脱敏。
  2. 以为差分隐私只能”加噪”不能训练 —— 其实 DP-SGD 就是普通 SGD 加”裁剪+加噪”两步，照常反向传播、照常收敛（§1.2）。代价是效用略降和调 ε/σ 的功夫，不是不能训练。
  3. 以为联邦学习天然防泄露 —— 其实”数据不出本地”只挡了”直接拿走数据”，挡不住 §4 的梯度反演：一次上行梯度就能像素级还原本地图。FL 必须叠加梯度加噪/剪枝/安全聚合才算有隐私。
  4. 以为模型记忆需要过拟合 —— 其实 Carlini 2021 证明 train/test loss 差极小也能逐字提取（§5.3）。”没过拟合=没泄漏”是错的，大模型容量本身就是记忆源。
  5. 以为小模型/低重复数据不会被提取 —— 其实只重复 33 次甚至只出现 1 次的序列（高熵 UUID、密码）也能被 GPT-2 提取；小模型只是量少不是安全（§5.3）。

10 检查点

  • 默写 DP-SGD 两步：裁剪 与加噪 ；说出 与 各钉住什么
  • 解释 ε 与 δ 的含义，说清”ε 大 = 隐私弱”（用 ε=1 vs ε=8 噪声 std 1.07 vs 0.13）
  • 默写 (ε,δ)-DP 定义式 ，说出 δ 典型上界
  • 用 CPU 跑通 P01，贴出攻击准确率 ≥0.8 且高于随机基线 0.5 的数字
  • 解释影子模型方法为何只需黑盒访问（用自身数据训影子、已知成员标签造攻击训练集）
  • 说出模型反演的优化目标（最大化目标类置信度），并指出它与 FGSM 的同构（梯度方向反一反）
  • 默写 DLG 梯度匹配目标 ，解释 batch 增大为何还原退化（平均稀释单样本梯度）
  • 说出 iDLG 怎么从梯度读标签（最后一层梯度符号），以及 DLG 防御里”剪枝 >20% 即有效”
  • 背出 Carlini 2021 的三个硬数字：604 条逐字记忆、最佳精度 67%、仅 33 次重复即被记
  • 说出 Nasr 2023 对 gpt-3.5-turbo 的 divergence 攻击提升倍数（150×）与查询成本（$200 捞出 1 万+ 条）
  • 用 CPU 跑通 P02，贴出 DP 模型测试精度下降 <10 点、MIA 优势被削弱的对比
  • 给定”多家医院联合训练且不可信中心”场景，选对技术组合（FL+DP）并说清各自挡什么（§6 表）

11 与主线的连接

  • → 模块 J §5（Inference：成员推断 / 模型反演 / 模型窃取）：本模块是 J §5 的工程化展开。J §5 只列了三类的名字和”防御=DP/FL”一句话；本模块把 MIA 写成可跑的 shadow model（§2 + P01），把模型反演写成梯度下降优化（§3），把”防御”落成 DP-SGD 两步（§1.2 + P02）。同构关系：J 的 Inference 攻击 = “模型输出/梯度泄漏训练信息”，本模块每节都在量化这个泄漏。
  • → 模块 K §2（模型逆向与信息提取 / LLM02 敏感信息泄露）：本模块 §5 是 K §2 的理论底子。K 说”LLM 会泄露训练数据”，本模块给出机理（k-eidetic 记忆化、似然比判据）与硬数字（Carlini 2021 的 604 条、Nasr 2023 的 150×）。共同结构：“模型记住了不该记的”——梯度反演（§4）是像素级版本，LLM 提取（§5）是文本版；两者防御都回到 DP 与输出截断。
  • → 模块 J §6（对抗训练）对照：DP 是”隐私侧”的代价约束，对抗训练是”鲁棒侧”的代价约束；读论文时两套都看”效用-保护 trade-off 曲线”，方法论同源。
  • → 模块 K §2 防御：K 的”训练前输入治理/去重”对应本模块 §5.5 的”去重+PII 清洗不够、必须 DP-SGD”。
